---
title: "Choosing an integration"
description: "Web Checkout or Direct API."
---

Cashd offers two integration options. Both use the same merchant account,
credentials, settlement stream, and reporting. The difference is who hosts the
payment step.

| | Web Checkout | Direct API |
|---|---|---|
| Payment page | Hosted by Cashd | Built by you |
| Who handles the customer's code | Cashd | You |
| Browser or in-app webview required | Yes | No |
| Bilingual and right-to-left screens | Provided | You build them |
| Failure messages | Provided | You build them |
| Your build | Two server calls and a return handler | Four calls and a full code-entry interface |
| Indicative duration | 1–2 weeks | 3–5 weeks |
| Works at a till or call centre | No | Yes |

## Choose Web Checkout if

- You sell online, in an app, or on a website.
- You are funding a customer wallet or store credit.
- You want the shortest path to launch.

## Choose Direct API if

- There is no browser or webview at your payment step.
- You serve the customer at a physical till, kiosk, or over the phone.
- The payment interface must stay inside your own product.

## Running both

You can run both on one merchant account — for example Web Checkout online and
Direct API in store. One set of credentials, one settlement stream.

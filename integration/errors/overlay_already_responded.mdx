| | |
|---|---|
| Code | `overlay_already_responded` |
| HTTP status | `409` |
| Class | Validation |
| Surface | Consumer app |
| Safe to retry | No |

## Message

Cashd returns this message in both languages. Render the one matching your
customer's locale.

> You've already responded to this survey.

## Cause

A response was already recorded for this survey. Not reachable by a partner integration.

## What to do

1. No partner action.

## Response shape

```json
{
  "error": {
    "code": "overlay_already_responded",
    "message_en": "...",
    "message_ar": "...",
    "doc_url": "https://docs.trycashd.com/integration/errors/overlay_already_responded",
    "request_id": "req_01HW..."
  }
}
```

Log `request_id` and quote it in any support request. See
[Error handling](/integration/errors/overview).

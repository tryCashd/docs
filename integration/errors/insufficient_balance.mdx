| | |
|---|---|
| Code | `insufficient_balance` |
| HTTP status | `422` |
| Class | Business |
| Surface | Merchant API |
| Safe to retry | No |

## Message

Cashd returns this message in both languages. Render the one matching your
customer's locale.

> The customer's balance is too low for this charge.
| Hint | Ask the customer to top up, or reduce the charge amount. |

## Cause

The requested amount exceeds the customer's available Cashd balance. It is also returned when the balance moved between your availability check and the charge — availability is not a reservation — or when a Cashd spending limit applies.

## What to do

1. Call `POST /merchant/availability` and charge `authorizable_halala` instead.
2. Collect the shortfall with another tender.
3. Do not retry the same amount.

## Response shape

```json
{
  "error": {
    "code": "insufficient_balance",
    "message_en": "...",
    "message_ar": "...",
    "doc_url": "https://docs.trycashd.com/integration/errors/insufficient_balance",
    "request_id": "req_01HW..."
  }
}
```

Log `request_id` and quote it in any support request. See
[Error handling](/integration/errors/overview).

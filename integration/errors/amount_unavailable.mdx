| | |
|---|---|
| Code | `amount_unavailable` |
| HTTP status | `422` |
| Class | Business |
| Surface | Hosted checkout |
| Safe to retry | Yes, with a smaller amount |

## Message

Cashd returns this message in both languages. Render the one matching your
customer's locale.

> This amount isn't available. Try a smaller amount.

## Cause

In the open-amount flow, the amount the customer entered exceeds their available Cashd balance. Returned only after the customer has verified control of the wallet.

## What to do

1. The customer enters a smaller amount on the same page.
2. No partner action. A sustained rate suggests customers do not know their balance before starting.

## Response shape

```json
{
  "error": {
    "code": "amount_unavailable",
    "message_en": "...",
    "message_ar": "...",
    "doc_url": "https://docs.trycashd.com/integration/errors/amount_unavailable",
    "request_id": "req_01HW..."
  }
}
```

Log `request_id` and quote it in any support request. See
[Error handling](/integration/errors/overview).

| | |
|---|---|
| Code | `reset_code_invalid` |
| HTTP status | `422` |
| Class | Authentication |
| Surface | Portal and app |
| Safe to retry | Yes, with a correct code |

## Message

Cashd returns this message in both languages. Render the one matching your
customer's locale.

> Incorrect code. Try again.

## Cause

The password-reset code is incorrect. The same response is returned for an unrecognised email address, so the endpoint cannot be used to discover which accounts exist.

## What to do

1. Re-enter the code.
2. Request a new code if it was not received.

## Response shape

```json
{
  "error": {
    "code": "reset_code_invalid",
    "message_en": "...",
    "message_ar": "...",
    "doc_url": "https://docs.trycashd.com/integration/errors/reset_code_invalid",
    "request_id": "req_01HW..."
  }
}
```

Log `request_id` and quote it in any support request. See
[Error handling](/integration/errors/overview).

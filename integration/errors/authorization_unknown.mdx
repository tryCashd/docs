title: "authorization_unknown"
description: "HTTP 502 — upstream error returned by the Cashd API."
---

| | |
|---|---|
| Code | `authorization_unknown` |
| HTTP status | `502` |
| Class | Upstream |
| Surface | Merchant API |
| Safe to retry | Read, never blind retry |

## Message

Cashd returns this message in both languages. Render the one matching your
customer's locale.

> The authorization status is currently unknown.

## Cause

The final state of the authorisation could not be determined. The wallet may have been debited.

## What to do

1. Read `GET /merchant/transactions/:id` and act on the returned status.
2. Do not treat this as a failure.
3. Do not create a second transaction for the same intent.

## Response shape

```json
{
  "error": {
    "code": "authorization_unknown",
    "message_en": "...",
    "message_ar": "...",
    "doc_url": "https://docs.trycashd.com/integration/errors/authorization_unknown",
    "request_id": "req_01HW..."
  }
}
```

Log `request_id` and quote it in any support request. See
[Error handling](/integration/errors/overview).

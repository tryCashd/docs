| | |
|---|---|
| Code | `no_balance` |
| HTTP status | `422` |
| Class | Business |
| Surface | Merchant API |
| Safe to retry | No |

## Message

Cashd returns this message in both languages. Render the one matching your
customer's locale.

> There is no balance available for this program.

## Cause

The customer has a Cashd account but no SAR balance to spend. They have not topped up, or have already spent what they converted.

## What to do

1. Offer another payment method.
2. The customer can top up in the Cashd app by converting loyalty points, then start again.

## Response shape

```json
{
  "error": {
    "code": "no_balance",
    "message_en": "...",
    "message_ar": "...",
    "doc_url": "https://docs.trycashd.com/integration/errors/no_balance",
    "request_id": "req_01HW..."
  }
}
```

Log `request_id` and quote it in any support request. See
[Error handling](/integration/errors/overview).

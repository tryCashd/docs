| | |
|---|---|
| Code | `checkout_session_expired` |
| HTTP status | `422` |
| Class | Business |
| Surface | Hosted checkout |
| Safe to retry | No |

## Message

Cashd returns this message in both languages. Render the one matching your
customer's locale.

> This payment has expired.
| Hint | Ask the cashier to start it again. |

## Cause

The checkout session passed its expiry before it was completed.

## What to do

1. Create a new session.
2. Consider a longer `expires_in_minutes` if this recurs on a slow journey.

## Response shape

```json
{
  "error": {
    "code": "checkout_session_expired",
    "message_en": "...",
    "message_ar": "...",
    "doc_url": "https://docs.trycashd.com/integration/errors/checkout_session_expired",
    "request_id": "req_01HW..."
  }
}
```

Log `request_id` and quote it in any support request. See
[Error handling](/integration/errors/overview).

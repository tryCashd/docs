---
title: "weak_password"
description: "HTTP 422 — validation error returned by the Cashd API."
---

| | |
|---|---|
| Code | `weak_password` |
| HTTP status | `422` |
| Class | Validation |
| Surface | Portal and app |
| Safe to retry | Yes, with a valid password |

## Message

Cashd returns this message in both languages. Render the one matching your
customer's locale.

> Your password must be at least 8 characters and include an uppercase letter, a lowercase letter, and a digit, and both entries must match.

## Cause

The password does not meet the complexity requirement, or the two entries do not match.

## What to do

1. Use at least 8 characters with an uppercase letter, a lowercase letter, and a digit.
2. Confirm both entries match.

## Response shape

```json
{
  "error": {
    "code": "weak_password",
    "message_en": "...",
    "message_ar": "...",
    "doc_url": "https://docs.trycashd.com/integration/errors/weak_password",
    "request_id": "req_01HW..."
  }
}
```

Log `request_id` and quote it in any support request. See
[Error handling](/integration/errors/overview).

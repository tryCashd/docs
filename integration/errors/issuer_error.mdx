---
title: "issuer_error"
description: "HTTP 502 — upstream error returned by the Cashd API."
---

| | |
|---|---|
| Code | `issuer_error` |
| HTTP status | `502` |
| Class | Upstream |
| Surface | Merchant API |
| Safe to retry | Yes, once |

## Message

Cashd returns this message in both languages. Render the one matching your
customer's locale.

> The charge couldn't be completed.
| Hint | Wait a moment and try again. If this persists, contact support. |

## Cause

An upstream system returned an error.

## What to do

1. Retry once.
2. Fall back to another payment method if it repeats.

## Response shape

```json
{
  "error": {
    "code": "issuer_error",
    "message_en": "...",
    "message_ar": "...",
    "doc_url": "https://docs.trycashd.com/integration/errors/issuer_error",
    "request_id": "req_01HW..."
  }
}
```

Log `request_id` and quote it in any support request. See
[Error handling](/integration/errors/overview).

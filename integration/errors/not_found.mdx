## Message

Cashd returns this message in both languages. Render the one matching your
customer's locale.

> Resource not found.

## Cause

The resource does not exist, or it does not belong to your merchant account. The two cases are deliberately indistinguishable.

## What to do

1. Confirm the identifier.
2. Confirm you are using the correct environment.
3. For `by_reference`, confirm a session was actually created with that reference.

## Response shape

```json
{
  "error": {
    "code": "not_found",
    "message_en": "...",
    "message_ar": "...",
    "doc_url": "https://docs.trycashd.com/integration/errors/not_found",
    "request_id": "req_01HW..."
  }
}
```

Log `request_id` and quote it in any support request. See
[Error handling](/integration/errors/overview).

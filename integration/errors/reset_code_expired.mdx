| | |
|---|---|
| Code | `reset_code_expired` |
| HTTP status | `422` |
| Class | Authentication |
| Surface | Portal and app |
| Safe to retry | No |

## Message

Cashd returns this message in both languages. Render the one matching your
customer's locale.

> This code has expired. Request a new one.

## Cause

The password-reset code passed its validity window.

## What to do

1. Request a new code.

## Response shape

```json
{
  "error": {
    "code": "reset_code_expired",
    "message_en": "...",
    "message_ar": "...",
    "doc_url": "https://docs.trycashd.com/integration/errors/reset_code_expired",
    "request_id": "req_01HW..."
  }
}
```

Log `request_id` and quote it in any support request. See
[Error handling](/integration/errors/overview).

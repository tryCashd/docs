| | |
|---|---|
| Code | `overlay_token_expired` |
| HTTP status | `410` |
| Class | Authentication |
| Surface | Consumer app |
| Safe to retry | No |

## Message

Cashd returns this message in both languages. Render the one matching your
customer's locale.

> This survey link has expired.

## Cause

A survey link passed its validity window. Not reachable by a partner integration.

## What to do

1. No partner action.

## Response shape

```json
{
  "error": {
    "code": "overlay_token_expired",
    "message_en": "...",
    "message_ar": "...",
    "doc_url": "https://docs.trycashd.com/integration/errors/overlay_token_expired",
    "request_id": "req_01HW..."
  }
}
```

Log `request_id` and quote it in any support request. See
[Error handling](/integration/errors/overview).

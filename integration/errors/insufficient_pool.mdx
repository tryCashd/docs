---
title: "insufficient_pool"
description: "HTTP 503 — upstream error returned by the Cashd API."
---

| | |
|---|---|
| Code | `insufficient_pool` |
| HTTP status | `503` |
| Class | Upstream |
| Surface | Merchant API |
| Safe to retry | Yes, after a delay |

## Message

Cashd returns this message in both languages. Render the one matching your
customer's locale.

> Cashd is temporarily unable to authorise new spend.
| Hint | Please retry shortly, or contact support if this persists. |

## Cause

A Cashd-side operational limit prevents new authorisations. It is not related to the customer's balance.

## What to do

1. Retry after a short delay.
2. Fall back to another payment method if it persists.
3. Raise with `ops@trycashd.com` if sustained.

## Response shape

```json
{
  "error": {
    "code": "insufficient_pool",
    "message_en": "...",
    "message_ar": "...",
    "doc_url": "https://docs.trycashd.com/integration/errors/insufficient_pool",
    "request_id": "req_01HW..."
  }
}
```

Log `request_id` and quote it in any support request. See
[Error handling](/integration/errors/overview).

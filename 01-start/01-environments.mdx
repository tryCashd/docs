| Environment | Purpose | Access |
|---|---|---|
| Non-production | Implementation and certification | Base URL and credentials issued by Cashd at account setup |
| Production | Live transactions | Base URL and credentials issued after certification |

Credentials are environment-specific and are not interchangeable. Non-production
keys carry the `sb` environment segment, production keys carry `live`. See
[Authentication](/01-start/02-authentication).

All paths in this documentation are relative to the base URL for your
environment, followed by `/api/v1`.

## Test accounts

Cashd issues designated test consumer accounts with your non-production
credentials. On those accounts, one-time code delivery may be substituted with a
fixed value so certification does not depend on SMS delivery. The accounts and
values are issued together with the credentials.

Do not use production consumer accounts for testing.

## Rate limits

Rate limits apply per environment and are stated at onboarding. Implement the
`429` handling described in [Error handling](/errors/overview)
regardless of the configured values.

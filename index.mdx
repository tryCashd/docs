Cashd converts loyalty points into SAR that consumers spend with participating
merchants. Consumers link their loyalty programmes into a Cashd wallet. Your
integration charges that wallet in SAR, and you are settled in SAR.

## Key facts

| Item | Value |
|---|---|
| Currency | SAR only |
| Money unit | Integer halala. 1 SAR = 100 halala |
| Consumer identifier | Saudi mobile number |
| Languages | Arabic and English on every consumer-facing surface |
| API version | v1 |

A merchant never learns which loyalty programme funded a transaction, or what a
consumer holds.

| | |
|---|---|
| Code | `checkout_unavailable` |
| HTTP status | `422` |
| Class | Business |
| Surface | Hosted checkout |
| Safe to retry | No |

## Message

Cashd returns this message in both languages. Render the one matching your
customer's locale.

> We couldn't start this payment. Please try another payment method.

## Cause

The hosted checkout page cannot proceed for this customer. It is a single generic decline that replaces the precise reasons available on the API-key rail, so the public page cannot be used to discover who holds a Cashd wallet.

## What to do

1. The customer uses another payment method.
2. No partner action; the precise reason is not disclosed on this surface by design.

## Response shape

```json
{
  "error": {
    "code": "checkout_unavailable",
    "message_en": "...",
    "message_ar": "...",
    "doc_url": "https://docs.trycashd.com/errors/checkout_unavailable",
    "request_id": "req_01HW..."
  }
}
```

Log `request_id` and quote it in any support request. See
[Error handling](/errors/overview).

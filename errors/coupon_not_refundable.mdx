| | |
|---|---|
| Code | `coupon_not_refundable` |
| HTTP status | `422` |
| Class | Business |
| Surface | Merchant API |
| Safe to retry | No |

## Message

Cashd returns this message in both languages. Render the one matching your
customer's locale.

> Coupon purchases can't be reversed.

## Cause

The transaction paid for a coupon. The coupon code was delivered to the
customer and may already be redeemed, so the sale is final.

## What to do

1. Do not retry.
2. Contact `ops@trycashd.com` with the transaction identifier if the sale must be reviewed.

## Response shape

```json
{
  "error": {
    "code": "coupon_not_refundable",
    "message_en": "...",
    "message_ar": "...",
    "doc_url": "https://docs.trycashd.com/errors/coupon_not_refundable",
    "request_id": "req_01HW..."
  }
}
```

Log `request_id` and quote it in any support request. See
[Error handling](/errors/overview).

| | |
|---|---|
| Code | `idempotency_key_too_long` |
| HTTP status | `400` |
| Class | Validation |
| Surface | Merchant API |
| Safe to retry | Yes, with a shorter key |

## Message

Cashd returns this message in both languages. Render the one matching your
customer's locale.

> X-Idempotency-Key exceeds the allowed length.

## Cause

The key exceeds 200 characters.

## What to do

1. Shorten the key. A UUID or ULID is sufficient.

## Response shape

```json
{
  "error": {
    "code": "idempotency_key_too_long",
    "message_en": "...",
    "message_ar": "...",
    "doc_url": "https://docs.trycashd.com/errors/idempotency_key_too_long",
    "request_id": "req_01HW..."
  }
}
```

Log `request_id` and quote it in any support request. See
[Error handling](/errors/overview).
